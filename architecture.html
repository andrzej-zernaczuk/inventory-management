Factory Inventory Management System

Full-stack demo: Vue 3 single-page app, FastAPI backend, in-memory data loaded from JSON files. No database.

System architecture

Tech stack

Frontend

  • Vue 3 (Composition API)
  • Vue Router 4
  • Axios
  • Vite 8 dev server / build
  • Custom SVG charts

Backend

  • Python 3.11+
  • FastAPI + Uvicorn
  • Pydantic 2 validation
  • uv for dependency management

Data

  • JSON files in server/data/
  • Loaded into memory at import time
  • Writes are not persisted

Testing and tooling

  • pytest + FastAPI TestClient
  • Backend tests in tests/backend/
  • Claude Code agents, skills, MCP config in .claude/

Data flow

  1. Filter change. The user changes Time Period, Warehouse, Category or Order Status in FilterBar. These live in the singleton refs of useFilters, so every view shares them.
  2. Request. A view calls getCurrentFilters() and passes the result to api.js, which appends only non-all values as query params.
  3. Filtering. FastAPI handlers run apply_filters (warehouse, category, status) and filter_by_month (month or quarter, matched on order_date) over the in-memory lists.
  4. Validation. Responses pass through Pydantic response_models; the dashboard summary aggregates totals (inventory value, low stock, pending orders, backlog).
  5. Render. The view stores the JSON in refs and derives chart and table values with computed properties.
